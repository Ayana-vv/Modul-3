Баг-репорты:
1. При создании сотрудника невозможно создать запись с пустыми полями
2. Когда в бд нет столбца (например: email), то в тесте можно добавить поле email (email предварительно добавлен в конструктор)
3. Удаляется сотрудник, хотя в body переданы данные другого сотрудника (валидация идёт только по id)
4. В SQL-запросе можно поменять на числовое значение, а в тесте формат поля String(например: поле city), в postman есть валидация на формат поля
